# dsh-wallpaper 壁纸

给 DeepSeek Harness 加全局壁纸，而且做到**每个界面一致**——不只是会话区后面有一张图。

[English](README.md) | 中文

## 功能

- **一张图，一套合成。** 不靠各面板各自不透明，插件会把它遍历到的表面（外框、栏目、侧栏、会话画布、输入框）按同一配方重新合成，壁纸在每处的透出权重相同——输入框与会话区的实测值完全一致。
- **图库 + 本地图片。** 在 **设置 → 壁纸** 里搜 [wallhaven.cc](https://wallhaven.cc)，或直接选本地图片；原图存在 `~/.dsh/wallpaper`。
- **实时滑杆。** 图片模糊、遮罩（veil）不透明度、面板不透明度、填充模式（覆盖/包含/平铺）改完即生效，不用刷新。
- **桌面端标题栏一体化。** Windows 桌面端的标题条与 Electron 窗口控件覆盖层默认是不透明的主题色；插件把那个主题变量指向透明，壁纸一直通到窗口顶边，拖拽区和最小化/最大化/关闭按钮照常可用。

## 安装

市场里：**设置 → 插件市场 → 壁纸 → 安装**（也会出现在市场的 **主题** 标签页）。

手动：

```sh
dsh plugin --profile desktop add dsh-wallpaper
```

## 配置

**设置 → 壁纸**：图片来源、模糊、遮罩不透明度、面板不透明度、填充模式。面板不透明度越低，壁纸越明显；设为 `0` 就只剩遮罩。

## 兼容性

- 任意 Harness Web 界面；标题栏一体化只在 Windows 桌面端生效（靠 preload 的标记识别）。
- 需要 Harness `0.2.0-rc.2` 或更新。
